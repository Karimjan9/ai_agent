# Instrument method library and agent selection learning

This delivery adds bounded research mechanisms, not a profitable Master or
Champion Council. Sources, library versions and agent skill have separate owners.

## Inventory and input

`php artisan trading:instrument-methods inventory --json` reads all 26
instrument usage cards in five groups and 13 playbooks without seeding trading
authority. `catalog` reads the checksum-pinned assistant-curated source plan;
`install` transactionally installs its exact immutable source/method/recipe
revisions, idempotently and without creating agent policies or qualification.
The delivered catalog covers eight method classes / ten revisions and three
hybrids. Six classes are existing prospective construction adapters; two classes
are genuine typed entry-veto methods with separate L1/L2 revisions. The remaining
18 instrument cards expose explicit implementation/data dependencies, not fake
executable skills. Eight primary references include original paraphrases,
licensing and unknown prior-exposure disclosures. Thresholds are lab hypotheses,
not claims attributed to those publishers.

Registration is explicit: `source`, `method`, `recipe`, `policy`,
`compile`, `attach`, `study`, `learn`, `propose`, `evolve`, `settle`, `status`.
Use `--input=absolute-json-file --json`. Inputs are bounded regular JSON files;
successful output does not echo source text. `source --fetch` is an explicit
bounded public-HTTPS fetch, not a background crawler. Video references accept
permitted imported captions with a timestamp; downloading all YouTube transcripts
or automatically converting vague narratives is not implemented.

Method fields: instrument_key, method_key, revision, context_predicate, horizon,
known_limitations, source_keys, implementation. Implementation is a supported
typed AST with target/input bindings/compute budget, or a schema-valid parameter
adapter. Recipes freeze method hashes and a compatible context. Compile takes
recipe_hash, baseline `{strategy_family,parameters}`, and pre-2026 scope
`{symbol,timeframe,data_hash,execution_hash,context_predicate}`. A policy compile
additionally requires policy_hash, agent_key and exact UTC evaluated bounds.

Policies freeze agent_key, revision, recipe_hashes, ordered contextual rules
and BASELINE/WAIT fallback. Each model must own `model:<id>` and receive binding
before any LabAgent, run, promotion or council use. A construction adapter that
changes the original vector requires a fresh constructor; it is not silently
applied after sealing. Runtime typed operators cannot create an entry direction,
increase hard risk or inject arbitrary external code.

## Actual use and agent learning

The actual PHP request builder attaches the exact selected model policy. Python
validates it before cache and execution, then records closed-input selection,
WAIT/context reason, real target use and behavior change. Methods unreachable
from the trade lifecycle report unreached, not a fabricated successful invocation.
Ordinary receipts are in data_quality.instrument_method_learning_receipt;
native receipts belong to their exact council member. Existing immutable
screening projection reopens original products before persisting experiences.

`learn` requires run_id. `propose` requires policy_hash, next revision and bounded
max_recipes. It is observational prioritization, not profitability-based Master.
`evolve` makes a fresh, same-baseline research model from the original proposal
and experience lineage. It does not dispatch a generation or promote a council.
The original library, models, exposure history and receipts are unchanged.

With `services.instrument_methods.generation_learning_enabled`, only newly
constructed ordinary generations pin the configured exact recipe hashes.
An eligible unused child receives its own new policy before any parameter/run
seal. Original parent experiences yield at most one bounded frozen proposal,
recompiled for the child's actual legal vector and new data scope. Server-owned
handoff provenance is verified again on use. Exact comparative/cooperative,
native council, passport and protected abstain/adversarial seats are unchanged;
their own experiment owner must explicitly declare an intervention. A generation
marker therefore does not imply that every seat received a method. Missing parent
evidence, unsupported adapters or scopes remain typed dependencies. Neither
proposals nor this observational inheritance confer economic/causal authority.

## Separated four-arm backtest

Before dispatch, `study` freezes study_key and four models/policies labeled
L1A1/L2A1/L1A2/L2A2, exact data/execution hashes, UTC context, evaluated_rows,
initial_balance, risk_per_trade, execution_costs, hard_limits, resource_caps
and minimum_trades. `settle` accepts study_hash plus exact original run IDs.
Neither late best-attempt selection nor incomplete/censored products certify
improvement. Library, selector conditional effects and interaction are separate.

`study-execute` registers the study hash and its exact canonical local CSV source
with the existing durable work kernel. The existing arbiter, canonical constructor
and `ExecuteScopedResearchArmJob` remain the only dispatch path. All four original
request hashes must pass preparation before the first arm is queued. The cohort
owns four declared carriers, not an alteration of an existing twenty-seat cohort.
Completed original arms are checkpointed and never replayed; source drift or an
original technical failure cannot be repaired by selecting another attempt.
Original comparison closes into local method experiences/proposals only. Study
observations are fenced out of ordinary historical advice, credit, paper and
generic screening fan-out. Bounded resource and current lease/source guards apply
at registration, claim, queue and publication.
Drain-first STOP permits only the already admitted four-request barrier to
finish. PAUSE and SAFETY_HALT do not. `research_reserved` remains active for
runtime status and reload guards even between queued originals. Canonical
execution-envelope usability cannot be mistaken for model trading authority
when rebasing a same-baseline research child; its exact costs are revalidated.

For local diagnostic software acceptance, the offline runner is:

```powershell
python scripts/backtest-instrument-method-matrix.py --spec C:/path/spec.json --output-dir C:/path/new-products
```

The spec protocol is instrument_method_matrix_spec_v1, with spec_key,
registered_at, data `{path,sha256,start,end,warmup_rows,max_rows,selected_rows}`,
minimum_trades, per_arm_timeout_seconds, and four arm request objects. Seal
spec_hash against canonical JSON and preserve the original spec_json copy.
All nonlearning request fields must match. L1/L2 libraries differ while each
library stays fixed across A1/A2. A2 is a preregistered candidate selector unless
its original learning provenance actually proves derivation. Bounds: at most
4096 input rows, 120 seconds per arm. No outcome-dependent retry or deadline
increase. Actual clocks, costs, ledgers, events and unchanged bytes are checked.

Outputs preserve the original four responses, process observations, pre-outcome
source snapshot and summary. Source/transport/timeout failures are technical;
small samples are underpowered. All outputs have false independent/economic/
credit/paper/live authority. Feature warmup, actual execution warmup and evaluated
clock are reported separately, not inferred from declared row counts.

## Delivery and qualification

Code is prepared in an isolated worktree. Tests are SQLite-only and Python local
execution; no production migration or active worker replacement is implicit.
Use the existing drain-first artifact/boot-attested release procedure. Never
attach to an admitted generation or relabel old data as independent. Pre-2026
research continues; 2026 and every later year remains paper-only.

Further qualifications are empirical: additional per-instrument approaches,
scope-specific independent issuer, specialist transfer/retention, native council
comparison and prospective paper behavior. A registry or a passing software
test does not establish any of them.
