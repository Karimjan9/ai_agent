not use. Forward council planning also repeatedly decoded each large metrics
document and computed state clusters for discarded candidates. The repair keeps
the same ranking, ties, recall and RNG, decodes one document per candidate and
computes clusters only for the selected regimes. It adds no persistent cache.

- Baseline `portfolioCouncilCurriculum` did not finish within its 20-second cap;
  its unused eager model query alone took 12.039 seconds.

This identifies and removes a real cost. It does not attribute all of the old
2,370-second constructor timeout to that function or prove a full constructor
now completes. Sparse diagnostic stages retain the exact attempt and original
expiry, without renewing its heartbeat or counting as scientific progress.

## Original historical exposure

The existing owner gains a finite, server-created source origin before first
exposure. It seals actual model/default/schema/selection/source identities and
reopens original immutable request/fold custody, including attempted failures.
Global reference inventory remains exclusion-only. Unknown prior history,
physical overlap, unproven market labels and drift must refuse the proof.

The cold recipe tests one fixed component question. It is not a claim that
guided selection learned to outperform blind selection. A new identifier or
birth record cannot make an old selected model or a reused window independent.

Native issuer integration also exposed an existing wrapper mismatch: the
canonical manifest verifier expects the sealed window, not its enclosing
readiness entry. That call is corrected without changing data admission.

The origin/capture seals now tolerate only SQL-added zero timestamp precision.
A SELECT-only MySQL probe confirmed that a whole-second DATETIME(6) reads back
as `2026-10-19 10:00:00.000000`. Nonzero fractional mutation remains refused;
no original row is rewritten and no generic hashing codec is changed.

Original history is checked before first issuance. A later reinspection may use
only the exact prefix in the already verified immutable original assessment;
caller-selected IDs cannot hide a later failed attempt before issuance. Every
row in the fixed prefix is streamed; the 32-item display cap is not an audit cap.
