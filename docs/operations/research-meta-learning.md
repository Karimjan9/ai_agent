# Evidence-bounded research meta-learning

This extends the existing memory, Academy, Foundry, portfolio and arbiter.
There is no second scheduler, arbitrary generated-code execution, provider
purchase, new trading authority, or retrospective upgrade of old evidence.
Implementation and test acceptance are distinct from deployment and market
acceptance. The 2026 paper-only policy remains unchanged.

## Native sequence

1. Existing portfolio allocates compatible seats. Optional complete question
   candidates receive bounded value/information/cost ranking and a seeded
   random-control share. Missing metadata retains the existing safe allocation;
   a recommendation does not create a job or bypass readiness.
2. Academy seals learning-progress tasks only for new trials. Existing frozen
   plans remain unchanged. Comparable completed stage evidence can recommend
   a bounded neighboring challenge, prerequisite repair or budget hold.
3. The first native causal fold preregisters a forecast after release binding
   and before request dispatch. Already-observed experiments cannot be
   preregistered. Later folds must use the same baseline, arm parameters,
   dataset, execution and evaluator/confirmation contract.
4. Only atomic original fold settlement calibrates that forecast. Three trades
   per arm/fold is a **local calibration** floor, not the scientific confirmation
   threshold. Unsupported/unmeasured targets and underpowered outcomes do not
   become negative skills. Missing resource measurements remain null; a wall
   budget is never represented as measured CPU.
5. The committed screening projection archives original behavior. Scope and
   sample protocol are part of the archive identity. Catalogue names, broad
   session labels and parameter distance do not establish behavioral diversity.
6. Foundry mines bounded, typed parameterized subtrees only from distinct solved
   original tasks. CALL nodes expand to the same sealed primitive AST before
   evaluation. Representation savings include the library definition cost.
   Semantic/task-transfer proof, interpreter cost and synthesis/search advantage
   are different claims. No missing search producer is replaced with made-up
   resource numbers.
7. A cheap rejection can enter one prospective randomized higher-fidelity
   audit; masked/unmasked measurement studies have their own exact producer
   lineage. These are research proposals/dependencies, not final skill verdicts.
8. Policy declarations can generate bounded challengers and run a fixed
   positive/null/poison/context-switch/interaction/misleading-proxy benchmark.
   Actual policy comparisons require a pre-registered panel of real, unobserved
   questions with equal caps. Neither synthetic success nor local positive PnL
   activates a new policy or grants inherited economic skill.

## Delivery and scientific limits

Run focused positive, poisoned, missing-proof, changed-source, scope-drift,
duplicate-delivery and future/as-of tests. Run Project Map impact/generate/check.
Seal the tested source only after active original cohorts drain. Apply the
additive migration, restart the canonical workers, verify their loaded hashes,
then resume through the existing owner. Do not hot-fix frozen running cohorts
or overwrite another session's changes.

An implementation receipt must explicitly state which code is committed,
which release workers actually loaded, and which real studies completed.
Prediction accuracy, search savings, audit false-negative rate, learning
progress, transfer utility and policy superiority require actual measured
questions. Unknown fields remain unknown. Authorized untouched research
windows cannot be manufactured from an old archive, new hash or provider.
