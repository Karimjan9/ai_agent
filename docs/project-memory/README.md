# Agent Project Memory

Bu papka loyihani qayta-qayta to'liq skan qilmasdan tushunish uchun ixcham, Obsidian-mos xotira qatlamidir.

## Agent protokoli

1. Ishni boshlashda avval [[project-index]] va vazifaga mos modul yozuvini o'qing.
2. Keyin faqat indeks ko'rsatgan fayllarni oching; barcha `app/`, `tests/` yoki `resources/` daraxtini ko'rib chiqish shart emas.
3. Kodga real o'zgarish kiritilsa, shu o'zgarishga tegishli modul yozuvi va `project-index.json`dagi `updated`/`change_log`ni yangilang.
4. Noaniq yoki eski bo'lib qolgan ma'lumotni `unverified` deb belgilang; uni fakt deb qabul qilmang.

## Navigatsiya

- [[project-index]] — mashina o'qishi uchun asosiy JSON indeks.
- [[architecture]] — komponentlar va asosiy data flow.
- [[modules]] — modullar, kirish nuqtalari va egalik chegaralari.
- [[operations]] — ishga tushirish, test va xavfsiz operatsion eslatmalar.
- [[ai-learning-laboratory]] — laboratoriya lifecycle, gate va scheduler qoidalari.
- [[market-data-continuity]] — Dukascopy outage recovery va candle continuity qoidalari.

`PROJECT_CONTEXT.md` tarixiy batafsil kontekst sifatida saqlanadi. Ushbu papka esa tezkor navigatsiya uchun birinchi manba hisoblanadi.
