# Cross-module flow: causal learning loop

## Purpose

Close a research experiment as an auditable unit of knowledge: it either earns
only the authority supported by evidence, opens one bounded next action, or
records a truthful terminal/deferred result.

```text
Laboratory diagnosis / Academy plan
  -> Sealed source-context experiment contract and frozen control
  -> Cohort construction + nine durable three-arm fold jobs
  -> 9/9 immutable receipts + no-replay aggregate
  -> Evidence, parity and claim settlement
  -> Conversion receipt + transactional outbox
  -> Next work, quarantine/archive or bounded paper observation
```

## Modules

Optional separated method research (ADR-040): untrusted source reference ->
immutable instrument method/recipe -> intrinsic library + agent-owned policy ->
prospective model/request binding -> actual ordinary/native decisions ->
original eligibility-checked experience -> bounded policy proposal/fresh
same-baseline candidate. A preregistered L1/L2 x A1/A2 diagnostic study separates
library and selector effects; its local outcomes cannot borrow confirmation,
credit or paper admission. Candidate preparation is not automatic dispatch.
An append-only source-practice curriculum can add exact method-specific
instruction to the existing26 lessons without changing v1. A matched archive
trial must distinguish a reached rule, a behavior delta and economic utility;
zero-use/default-baseline traces are not skill-use evidence. Only requested new
reviewed methods select the new teaching version; old-only packs remain v1.
V2 packs pin completed curator observations separately from agent-owned practice.
An explicit fresh trend-entry variant uses the normal constructor/strategy owner
before filter selection. Future typed mixed-role recipe pools select a matching
current-phase target without falling through a selected veto/missing input;
legacy contracts preserve their original selection. None of these transitions
confers economic skill, independent confirmation or trading authority.
Explicit original method studies register one durable work -> existing arbiter
claim -> canonical four-carrier constructor -> all-four request-hash barrier ->
one fenced scoped-arm job at a time -> exact original comparison -> method-only
experiences/proposals -> terminal cohort/work. Ordinary historical advice and
economic projections exclude this purpose. New eligible ordinary children may
consume rederived parent proposals before seals; exact protected owners are not
unilaterally modified.

An explicitly prepared own-policy follow-up maps the unchanged original parent
and observational child policies to fixed L1/L2 recipe classes -> atomically
creates four signed unused carriers -> registers existing original work ->
the same canonical barrier/dispatcher/comparison. An unchanged policy class
returns no_effect without consuming replay resources. Source facts and proposal
root are retained; reused archive data does not become independent validation.

Original mature ENTRY/close products may separately feed a preregistered finite
meta training owner -> fixed-bin training plus chronological seen calibration
-> signed numeric asset -> unused ordinary-model attachment before seals ->
exact physical evaluation binding -> closed/as-of ENTRY score. Underpowered
sources issue no asset. This diagnostic path neither creates independent
confirmation nor transfers an asset silently across changed child parameters
or native shared accounts. The separate native protocol instead reopens exact
member-position outcomes and reconciled shared account -> fixed chronological
fit -> signed unused council/member target -> meta-free physical programmes ->
bound final native request -> actual closed-entry score. Native v1 pins peer and
subject policies, mode, account and inherited runtime ports; peer assets,
upgrades or incompatible window contracts remain refused. It is not a dispatch
or independent skill/Champion certificate.

The separate native v1 issuer reopens native original member/position/account
evidence -> fits the same bounded numeric algorithm -> preregisters one unused
draft council/member target -> canonical two-stage native compile -> actual
full parent request/clock/policy binding -> original native score/decision
receipt. Exact subject/peer policy and inherited runtime ports are required;
ordinary assets, peer learned assets, upgrades and missing features refuse.
This route creates no new scheduler, independent evidence or economic credit.

- `causal-learning`: experiment interpretation, receipt and next-work routing.
- `laboratory`: cohort lifecycle, provenance and research gates.
- `laravel-python-contract`: deterministic computation/attestation boundary.
- `confirmation-entry`: stage-specific executable behavior under study.
- `paper-execution`: paper-only observation after the separately earned gate.

## Invariants

- Work, evidence, causal claim, economic claim and authority remain orthogonal.
- A result is not promotion evidence merely because it is terminal or positive.
- Conversion must be idempotent and must not leave terminal work orphaned.
- A completed fold is never replayed after restart; partial fold sets cannot
  settle or create causal credit.
- A confirmed local lesson cannot leak into another context or be forgotten by
  a later receipt that merely omits already sealed window counts.
- Performance/Economic Parent authority is a separate 2026 paper transition,
  not a side effect of historical forward replay.
- Current code/tests decide exact behavior; this flow is the cross-module map.

Explicit historical first-exposure questions seal their model and selection
before new exposure, using today's actual clock and pre-2026 market data.
Registration then capture precede any admitted run. The original provenance
audit remains a separate issuance guard; a new registration or capture never
proves that historical data was untouched. Legacy seals retain their contract
(ADR-038). All events from 2026 onward remain paper-only (ADR-037).
