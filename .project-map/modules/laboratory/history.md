# Laboratory history

## 2026-08 — Pair-owned evidence and adaptive parent selection

The laboratory became explicitly provenance- and control-aware: dynamic parent
selection may use qualified contributors, while each child still repeats normal
replay, holdout and paper gates. See the detailed laboratory and adaptive
evolution memory for the current contract.

## 2026-09 — Project Map adoption

Laboratory intent, lifecycle navigation and source anchors moved into the
canonical Project Map. This is a navigation change, not a lifecycle-policy
change.

## 2026-09 — Dynamic scientific block allocation

The 20-seat population is allocated among exact pair, causal, factorial,
replication and guard blocks using evidence priorities. Static semantic groups
remain only a fallback scaffold; lifecycle and exact-control gates are unchanged.

## 2026-09 - Terminal full-validation boundary

Generation closure now covers a fully settled `full_validation` projection as
well as screening. Terminal technical children produce an honest generation
quarantine, while monitoring reports the cohort as closed work and preserves a
separate failed technical-integrity verdict.

## 2026-09 - Closed-MTF autonomous replay

The XAUUSD H1 population key is now explicitly storage-only. Generation
dispatch freezes one M5 execution plus H4/H1/M15 context bundle, and screening
and full validation retain that exact identity across the Laravel/Python handoff.

## 2026-09 - Consecutive autonomy receipts

A clean terminal generation is sealed only after the research-loop arbiter
creates its successor. Two consecutive linked receipts now form the strict
unattended lifecycle proof; zero-pass scientific abstention remains valid while
technical or incomplete evidence breaks the streak.

The receipt protocol also verifies how each source generation was created: its
trigger context must identify the exact completed arbiter writer decision and
the preceding generation. Successor creation provenance is retained when a
predecessor fails audit, while the autonomy receipt remains absent.

## 2026-09 - Evidence Portfolio activation probe

Cold-start construction may now reserve one research-only four-arm activation
block for a vetted strategy-to-tactic gap. The control copies the exact source
vector, and prequeue admission checks common manifest, arm hashes and exact
C/A/B/A+B deltas. Incumbent context elites are preserved as a separate
portfolio tier; the activation challenger receives no authority. See ADR-009.
