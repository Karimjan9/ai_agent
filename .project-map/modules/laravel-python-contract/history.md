# Laravel/Python contract history

## 2026-08 — Canonical identity and attestation hardening

Execution, data, strategy and management identities were made explicit across
runtime boundaries. Entry projections and fill admission are verified against
sealed copies where their protocol requires it.

## 2026-09 — Project Map adoption

The handoff now has an explicit ownership map and transition checklist; the API
contract remains authoritative in `docs/ai-service-contract.md`.

## 2026-09 — Runtime composition attestation

Replay responses expose actual component and instrument activation rather than
treating assignment as execution. Laravel validates that trace before causal
composition or bundle settlement.

## 2026-09 - Executable composition ownership

Frozen composition passports now own final constructor identity. Python
validates all four component bindings before replay, applies explicit tactic and
management adapters, and accepts only backtester-emitted node receipts for
whole-composition consumption.

## 2026-09 - Autonomous closed-MTF replay handoff

Ordinary XAUUSD generations now freeze one M5/H4/H1/M15 manifest before queue
admission. Screening and full replay execute on M5, while Python fails closed on
missing, path-drifted or hash-drifted context instead of silently replaying H1.

## 2026-09 - Dataset-scoped historical volume handoff

Laravel now derives replay volume context from the frozen foundation or MTF
manifest, not from the rolling live audit. Python reports no-volume controls as
`not_requested`; active volume lanes still fail closed without marker coverage
and provenance for the exact replay hash.

## 2026-09 - Aggregate executable organism authority

Composition protocol v3 binds component identities, instrument assignment,
dataset/MTF and execution identity in one contract. The typed pipeline owns the
final pre-risk signal, and `consumed` requires hash-valid receipts from all
required nodes plus a completed managed trade.

## 2026-09 - Single-decision organism witness

The v2 typed program now seals its protocol and complete decision topology.
Per-signal receipts retain first veto and exact decision/candle/manifest
identity through MTF permission, risk, fill and managed trade close. Whole-
organism consumption and settlement require one completed decision witness;
aggregate counters from different opportunities cannot substitute for it.

## 2026-09 - Gate-owned receipts and stale assignment closure

Typed pre-entry receipts are now emitted when the signal gate runs; the final
trace consumes their hash-bound chain rather than recalculating stage predicates.
Instrument assignments now derive their source components from the frozen
passport, and a cached assignment is invalidated when any source identity
drifts. Python independently rejects a rehashed stale source before replay.
