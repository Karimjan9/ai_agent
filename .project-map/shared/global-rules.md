# Global rules

- Research, replay and paper evidence are separate from live-trading authority.
- Every physical observation from 2026-01-01 onward is permanently paper-only,
  including 2027 and every later year. Research, selection, validation,
  training, warmup and context inputs must finish before that boundary.
  Independent authority additionally requires original untouched provenance;
  renaming a historical file or provider does not establish independence.
- Missing, stale or hash-invalid evidence fails closed where the underlying
  contract requires it; a map must never weaken that behavior.
- Laravel and Python share versioned, canonicalized cross-runtime contracts.
- Idempotency, immutable decision/evidence receipts and data provenance are
  behavior, not optional documentation.
- A discovery index is a shortcut to real code and tests, never a substitute.
- Do not introduce a second canonical map elsewhere in the repository.
