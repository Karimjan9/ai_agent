# ADR-024: Explicit clean discovery without full-archive substitution

Date: 2026-10-04
Status: accepted

## Decision

Keep full-archive continuity and independent validation as separate dependencies.
Where actual provider proofs cannot recover every historical bucket, the existing
MTF owner may explicitly freeze a new calendar-selected clean discovery bundle:
15000 evaluated M5 rows plus 512 warmup, closed H4/H1/M15 context, verified
native parent receipt, actual SQL economic rows and new file hashes.
Selection uses continuity/recency, never strategy results. Missing quotes remain
unavailable; their exact selected-stream provenance must be separately supplied.

Only a stored explicitly selected bundle may enter bounded Academy screening
through the existing arbiter and canonical dispatcher. The existing probe-window
contract enforces actual rows, warmup exclusion, UTC bounds and month counts.
Full evaluation/dispatch and direct Python non-incremental replay reject this
typed bundle. It certifies neither the incomplete parent nor independent,
paper, promotion or inherited skill authority.

The cold allowance binds physical parent fork/economic rows, foundation and
execution. Re-slicing, quote coverage, code edits and labels cannot renew it.
After this allowance is unavailable, the arbiter rechecks the original full-input
fence rather than using a clean slice to unlock a generic full successor.
Existing failed generations, scientific attempt caps and receipts stay immutable.

Provider transport failures must remain failures. The recovery and quote tick
boundaries never persist an empty/unattested response as observed absence.
Recovery may reuse only fully reverified prior successful proofs and fetch the
unresolved targets into another content-addressed fork.

## Consequences

Discovery can continue on honest clean data without pretending that a short
period repaired the full archive or supplies untouched evidence. Independent
confirmation still waits for genuinely authorized, unused data under the existing
2026 paper-only policy. A clean scope can produce a negative/null scientific
result; it cannot guarantee a profitable improvement or reset search budgets.
