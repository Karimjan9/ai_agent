# ADR-020: Executable capability truth and bounded instrument closure

Status: accepted
Date: 2026-09-29

## Decision

Use existing instrument registry, assignment, frontier, arbiter and ledger
owners; do not add a second learning authority. A code-owned capability card
declares parameter surface, exact event hook, data/context inputs, required
stage and ablation meaning. It distinguishes parameter adapters, OHLC proxies
and unimplemented descriptions. Management profile count is not engine count;
the current adapter is explicitly simplified, not full pyramiding or structural
timeframe escalation.

Discovery ranking uses only sealed source opportunities/data/stage facts. It
does not maximize backtest P/L or reselect on validation results. An ordinary
pair keeps its treatment identity; support inventory is limited to surfaces
actually bound by its model, with central safety ownership unchanged.
Generic mutation genes are resolved against the source's sealed strategy
family rather than a default instrument name. Four-seat activation work needs
both axes to have observed source opportunity, stage reachability, data and a
prospectively freezable exact control. Unknown evaluation count remains
unknown; no retrospective phase or artificial uncertainty is assigned.

Recover missing instrument projections with one bounded arbiter SQL child.
Candidate credit still needs the existing exact paired-context/window gates.
Frozen-control invocations are reference evidence and close without credit
only when their own attested assignment/run matches the exact pair. Locks
and open-row guards prevent retry from rewriting terminal history. Historical
reference housekeeping is rate-limited so it cannot delay every new cohort.

Economic C/A/B/A+B diagnostics require four unique finite arm observations and
the same data, MTF, execution, context and session identities. Recompute main,
interaction and removal effects from those observations; marginal bundle value
is not synergy, and activation-only discovery never grants economic credit.
Retained descendant benefit requires an actual ablated child model plus
eligible same-context frozen-control and trait-ablation comparisons. Boolean
outcome labels alone cannot satisfy that progress measure.

## Acceptance and limits

Focused tests exercise capability truth, missing data, unreachable downstream
stages, paired reference closure and retry, arbiter deduplication, and poisoned
factorial identity/value rejection. Monitoring exposes independent-validation
dependencies and separately measured retained-benefit outcomes. No authorized
research window, market advantage, inherited improvement or paper/live
permission is fabricated. The operator's 2026 paper-only boundary is retained.
