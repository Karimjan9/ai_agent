# ADR-003: A composition passport is executable runtime authority

## Decision

After contextual allocation and control pairing, the frozen composition
passport reclaims final ownership of the constructor's strategy family,
architecture and tactic. Laravel exports exact strategy, tactic, risk and
management bindings as one aggregate authority with the exact instrument
assignment, dataset/MTF bundle, execution assumptions, symbol and execution
timeframe. Python validates them before replay, applies bounded tactic,
typed-entry and management adapters, and attests only hash-bound node receipts
emitted inside the backtester decision path.

## Why

Post-hoc comparison allowed a valid declaration to coexist with a different
runtime model, while management was permanently unbound. Result totals could
then look partially observed even though the declared organism could never be
executed as one unit.

## Consequences

- A drifted or unsupported passport fails construction or replay before it can
  create scientific evidence.
- A tactic may only preserve a strategy signal or narrow it to WAIT; it cannot
  synthesize an opportunity.
- The typed entry pipeline owns the final pre-risk signal; a failed node cannot
  bypass directly into the central risk governor.
- Management profiles compile to explicit replay parameters without changing
  the risk governor's owned gene.
- Parameter binding and node execution remain separate: risk or management
  receives runtime credit only when its decision path is actually reached.
- Whole-composition settlement still requires every typed node receipt and all
  independent evidence gates; configuration alone grants no causal credit.
- `partially_observed` describes a valid but not fully activated organism. A
  component, node or aggregate-authority mismatch is a terminal technical
  failure for that immutable candidate.
