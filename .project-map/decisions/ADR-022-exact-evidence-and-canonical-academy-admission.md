# ADR-022: Exact evidence scopes and canonical Academy admission

Date: 2026-10-03
Status: accepted

## Decision

Keep the existing research arbiter as the only autonomous admission owner.
Academy materialization atomically creates one locked draft and pollable trial
intent, without directly publishing evaluator jobs. The arbiter separately
dispatches that same generation through normal dataset/MTF/release/snapshot
admission. Undelivered publication has two bounded transport retries; semantic
refusal and executed failure are not publication retries.

Evidence is scoped to what actually ran. File-sealed replay cannot accept inline
replacements; source-byte and consumed-row attestations survive cache and feature
boundaries. Stage proof requires ordered per-decision event identity, not equal
counts. V2 includes direction/geometry/entry-linked outcome semantics and actual
consumed context-stream/as-of dependencies. Incomplete evidence cannot retire
an axis; at-least-once callbacks do not become repeated scientific observations.
Setup topology declares its actual context/location/setup footprint. Academy
uses strict diagnostic producer flags, runtime-active cold-start axes, and an
immutable exact-source admission fence before trial planning. Eligible local
progress creates a distinct candidate-baseline passport instead of rewriting
the original source or claiming independent economic skill.

A cold Academy without a prospective source may open one bounded new discovery
cohort per stable research-data/execution scope. Archived parameters supply a
hypothesis, not proof. A pure compiler preview precedes the arbiter decision;
current pre-2026 foundation/MTF/execution/evaluator seals precede passport and
trial creation. The same prepare/dispatch owner and restart identity apply.
Changing evaluator code does not replenish this budget or exhausted historical
Edge compiler allowances.

Exactly one technical replacement is permitted for that original cold cohort
only when twenty original draft agents carry the exact attested missing-identity
quarantines and no evaluation run, artifact, gate outcome or score exists. A
changed source must fix the constructor seal; the original question, data,
execution, stable budget and history remain unchanged. This is not a scientific
retry, publication retry or another discovery allowance. Other failures,
observed outcomes and an already-used technical replacement remain blocked.

The approved preparation-copy fault adds one distinct technical allowance,
not another discovery question. Original bounded operational error envelopes,
sealed request and request-bound `snapshot_loaded` checkpoint must attest
zero scientific output. Its durable approved disposition precedes scoped
generation-batch cancellation; active attempts are never killed, and closure
waits for active/queue drain. Shared recovery revalidates those artifacts.
The fresh arbiter-only repair changes source/IDs, not primary or sixteen
preregistered kernel parameter vectors, data/MTF/cost or scientific budget.
Original + one constructor repair + one preparation repair is at most three;
observed outcomes and further failures cannot reset or extend this allowance.

A native historical unexpected-candle-gap refusal with original sealed request,
model and zero-output response closes transient retry debt as a data dependency.
The actual bad M5 SHA remains fenced before fresh construction and queue
admission. Provider recovery creates a different content-addressed training
archive only; existing price rows, generations and attempt budgets are immutable.
Native M5/M1 and raw ticks must agree for every recovered bucket, while sparse
minutes and residual calendar gaps stay explicit. The existing MTF owner
validates original/new bytes and database row digest, then freezes new price
input and separately re-bound quotes. Changing labels, source code or restoring
one screening window does not prove full-archive continuity or independent data.

Primary and kernel constructors stamp their own current-family identity using
the shared schema canonicalizer and existing universal local-adapter owner;
post-hydration draft guards are unchanged. Confirmation Academy research freezes
a fresh explicit-owner executable strategy/tactic passport with parameter-
preserving management, not the source's incompatible historical passport.
All raw sealed parameters and risks remain exact; the no-override manager cannot
silently replace them with profile defaults. Generic planner rotation excludes
this owner-only specification, and actual MTF protocol/four-stream seals remain
mandatory before model creation.

Creation persists exact primary control admission ownership and per-kernel-pair
control IDs before dispatch. Academy's compiler-bound shared instrument surface
is a distinct multi-arm research reservation, not a fabricated ordinary pair:
it changes neither economic/credit guards nor immutable control-first admission.

Admission is continuation-first across lanes, not merely within one lane's
numeric priority. Existing closure/recovery/durable obligations remain first.
Ready director proof and an Academy successor attested from its original settled
trial precede all fresh-discovery branches. A planned label or stage depth alone
cannot earn that priority. The bounded cold cohort also precedes new discovery;
its stable-input cap prevents perpetual new cold starts. One read-only director
plan is reused. Direct settlement rechecks frozen source/dependency seals and
the complete compiled primary-arm roster, so callers cannot bypass materializer
guards when claiming scaffold advancement.

The aggregate PHP/runtime fingerprint is not the Python-only boot fingerprint.
Preserve the old Python receipt field's meaning and add explicit full-runtime
and Python fields. The validated release carries the aggregate descriptor;
actual Python source/boot checks attest Python imports. PHP compares both scopes
to separate frozen identities. This additive boundary prevents a valid Python
receipt from being falsely rejected as an aggregate-hash mismatch and avoids
re-labelling legacy single-hash evidence as a dual-source proof.

Instrument authorized validation statistics are partitioned by research epoch
and exact intervention identity. Discovery remains visible but never acquires
retrospective validation authority. Recommendations and successor application
carry only the tested gene old/new/context/source delta.

E3/E4 admission reuse and paper capture/fill require the original frozen candidate
identity; no legacy admission is backfilled. External idea dedup/routing binds
the complete declared experimental design instead of relabelling it novelty.

## Consequences

Legacy count-only stage proof and unscoped posterior labels remain non-controlling.
Historical evidence is preserved. Complete fixture tests prove these integration
boundaries, not market advantage, independent research data availability or
paper/live permission. The 2026 paper-only policy is unchanged.
