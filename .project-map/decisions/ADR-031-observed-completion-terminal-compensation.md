# ADR-031 - Observed-completion zero-authority terminal compensation

## Context

G261 completed six original replay runs and immutable council feedback, but the
ADR-030 projection withholding left six constructor mutation-selection episodes
open. The settlement watermark therefore correctly refused generation closure.
A completed no-op lifecycle command was not proof that the generation settled.

## Decision

The existing canonical terminal boundary invokes a scoped compensation owner.
It verifies the original signed/root-capped work, exact six-seat vectors,
immutable request/response/release evidence, withholding events and terminal
assessment/feedback. It appends idempotent zero-authority episode settlements;
generic consolidation, scientific credit and mentor/posterior fan-out do not run.
Technical feedback remains technical in the mutable generation projection.
Original agents, screening decisions, runs, comparison and feedback stay unchanged.
Blocked settle-only boundaries report a typed deferred result, not CYCLE_ADVANCED.

Default rolling-reload preflight remains strict. An explicit read-only named
terminal-projection cold-maintenance mode accepts only that sole active observed
cohort after original physical work is complete, all reserved/pending/delayed
queues are known-empty and the operator control is drain-first STOP. It refuses
PAUSE, running admission, safety halt, unknown proof or another active cohort.
Fresh authenticated replay-idle probes remain required; it does not restart,
dispatch or write by itself. Exact owners cold-restart on a verified source,
then the same canonical drain closes the old projection before START admission.

## Limits

No manual database/queue reset, retrospective clock, metric zero-filling,
re-evaluation of old feedback or second observed-completion allowance follows.
Different or missing producer clocks and account metrics remain unassessable.
Independent validation stays separately authorized; 2026 remains paper-only.
This compensation closes operational lifecycle debt, not causal skill or profit.
