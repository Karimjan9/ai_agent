# ADR-025: One unchanged-question MTF validator replacement

Date: 2026-10-04
Status: accepted

## Decision

The existing Academy materializer may propose one
`academy_unobserved_mtf_validator_replacement_v1` only for an original terminal,
drained clean-discovery cold cohort whose immutable native error is exactly
`AUTONOMOUS_MTF_MANIFEST_INVALID`, before any scientific result.

Every arm must be covered: original request/runtime/release and technical
response evidence for attempted controls, or the canonical exact-control
admission refusal for an unexecuted dependent. Missing arms, observations,
changed data/cost, stale identities or another failure shape deny the proposal.
The old trial and all evidence remain terminal and immutable.

Both full and Python source seals must change. All original primary and kernel
parameter vectors, baseline, dataset/MTF, cost, question and physical-parent
budget remain exact. The existing arbiter and laboratory lock re-attest and
prepare fresh IDs; the canonical dispatcher alone admits replay. There is no
new scheduler, scientific credit or independence assertion.

This allowance is an alternative to the constructor/preparation repair chain:
original plus one validator replacement, never another replacement afterward.
Re-slicing, code edits or quote labels cannot reset that cap. A completed
scientific result is not eligible even when negative or underpowered.

## Consequences

A verified deterministic pre-execution validator defect can be repaired without
permanently spending a hypothesis that was never evaluated. Failed history is
not rewritten, and outcome-selected repeated testing remains forbidden.
The API and native closed-MTF runtime share the existing discovery scope/probe
guard; recognizing its incremental bundle never waives four-stream path/SHA,
full replay, independent research or 2026 paper-only boundaries.
